# Cart Page Project

This is a cart page layout built with HTML, CSS (Flexbox & Grid), and designed to be fully responsive across different screen sizes. It includes sections like the header, breadcrumbs, cart items, checkout totals, and footer, all styled with attention to user experience and mobile-first design principles.

## Features

- **Responsive Design**: Optimized for various screen sizes using media queries.
- **Cart Functionality**: Displays cart items with product images, details, and quantity inputs.
- **Breadcrumb Navigation**: Allows users to easily navigate back to previous pages.
- **Checkout Button**: A styled checkout button with hover effects.
- **Footer**: A multi-column footer with contact and other information.

## Technologies Used

- **HTML5**: For structuring the content.
- **CSS3**: For styling the page using Flexbox and Grid.
- **Media Queries**: For making the layout responsive.
